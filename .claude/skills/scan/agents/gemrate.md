# GemRate card page (agents B, C and E each do this alone)

- **Route:** open `https://www.gemrate.com/universal-search`, triple-click the search box so old text is replaced, type the query, wait 3 seconds and read the results with `get_page_text`. A card can have one entry per grader. Take the entry that agrees on set, number and language. If the set code was not legible on the card, match on name, number and size. Prefer the PSA-only entry; if there is only a universal entry, use its PSA row. If several agree, use the jev rule. Click that entry's tile by coordinates (take one screenshot to place the click), wait 3 seconds and read the page. **Fallback:** `find` the tile and click its ref. If the page says "Card not found", go back to the search and click again with the other method, once. Never load a card URL directly: it returns "Card not found".
- CardLadder cannot be searched by text (it asks for a sign-in), so its link has to come from this card page. This is why agents B, C and E each repeat this lookup instead of waiting for one another.
